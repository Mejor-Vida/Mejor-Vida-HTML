1. Application overview

Mejor Vida Insurance operates a password-protected internal Staff CRM at https://www.mejorvidainsurance.com/staff/crm.html. The CRM includes a Funnel Analytics dashboard used by our employees to review marketing performance for our own Google Search campaigns.

We are requesting Google Ads API Basic Access to add read-only keyword click reporting to this internal dashboard. The tool is not offered to external customers, agencies, or third parties.

2. Business model

Mejor Vida Insurance is a bilingual final expense life insurance agency. We are the advertiser — we run Google Ads for our own business to generate leads for our own products. We do not resell API access, manage other companies’ accounts, or operate a SaaS product.

3. Intended users

Internal users only. Access requires staff authentication to our CRM. Estimated users: 1–5 Mejor Vida employees (agents and administrators).

4. Problem being solved

Our staff need to see which search keywords receive ad clicks during a selected date range, alongside funnel and landing-page analytics already shown in the CRM. Today, keyword-level click data is not available from our first-party site tracking alone. We need read-only reporting from the Google Ads API for our own account.

5. Architecture

ComponentDescription
FrontendStaff CRM web app (static HTML/JS), Funnel Analytics tab “LP Google ads”
BackendServerless API route on Vercel: GET /api/staff/funnel-analytics
Google Ads integrationNode.js module calls Google Ads API REST googleAds:searchStream
AuthOAuth 2.0 refresh token (staff-initiated one-time setup); developer token in server env
HostingVercel (mejorvidainsurance.com)

Data flow: Staff user selects date range in CRM → backend queries Google Ads API → keyword click totals returned as JSON → displayed in dashboard table. No data is written back to Google Ads.

6. Google Ads API usage

Access type: Read-only reporting.

Resources / views:

  • keyword_view — keyword text and click metrics

Example GAQL query:

SELECT ad_group_criterion.keyword.text, metrics.clicks FROM keyword_view WHERE segments.date BETWEEN 'YYYY-MM-DD' AND 'YYYY-MM-DD' AND metrics.clicks > 0

Operations we do NOT perform:

  • No campaign, ad group, keyword, or bid creation or modification
  • No budget changes
  • No account linking or user management via API
  • No bulk mutates

7. Authentication and security

  • Developer token, OAuth client secret, and refresh token stored only in server environment variables (Vercel / local .env).
  • Secrets are never exposed to browsers or end users.
  • CRM endpoints require staff login before any analytics data is returned.
  • OAuth scope: https://www.googleapis.com/auth/adwords
  • Google Cloud project: cursor-sheets (OAuth client used for staff authorization)

8. Expected call volume

Low volume. Staff manually load the dashboard a few times per day. Each page load triggers one searchStream request for keyword clicks for the selected date range (typically 7–30 days).

Estimated usage: fewer than 50 API operations per day — well under Basic Access limits.

9. Data handling and retention

  • Keyword click aggregates are computed at request time and returned to the authenticated staff session.
  • We do not store raw Google Ads API responses in a public database.
  • Data is used solely for internal performance review of our own advertising.
  • No personal user data from Google Ads is collected or resold.

10. Compliance

  • Tool is for Mejor Vida Insurance’s own Google Ads accounts only.
  • Not a third-party tool; not distributed externally.
  • We will comply with Google Ads API Terms and applicable policies.
