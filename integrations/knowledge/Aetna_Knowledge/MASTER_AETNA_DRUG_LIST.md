# Accendo Final Expense — Declination drug list (agent / staff RAG only)

**Carrier:** Accendo Insurance Company (Aetna Senior Supplemental / CVS affiliate)

**Source:** Accendo FE Drug List (portal Reference Material), text extract updated 6/25/20

**Audience:** Staff assistant / agents only — do NOT republish full drug list on public website or consumer chatbot.


## How to use this list

- A “•” under Preferred / Standard / Modified means the medication is **unacceptable** for that plan (for the listed condition, or any condition if none listed).

- Capitalized names = brand; lowercase = generic.

- If Level Preferred is blocked, check Level Standard or Modified — applicant may still qualify.

- New drugs for declinable conditions appear regularly; if unsure, contact Accendo underwriting.

- Dual-purpose meds require the prescribed condition to be recorded on the app.

- Always ask application health questions as written; drug list supplements Rx/MIB automated review.
