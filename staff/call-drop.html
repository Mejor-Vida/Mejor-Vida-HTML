The easy way (from Notes)

  1. Do this once: add the contact below, and save this iPhone’s number.
  2. After each call, open the Note.
  3. Tap the Share button (square with an arrow).
  4. Tap Messages, send it to CRM Call Drop.

That text is the whole move. You do not copy the file into Grok. If the Note has the written transcript, share the text. If it is only a sound file, share the file — a long recording may be too big for a text, so use the backup below.
