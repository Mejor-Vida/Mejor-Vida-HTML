# Weekly blog drafts

Sunday Cursor runs save draft HTML here per `tools/weekly-blog-system-rules.md`.

- `content-package-YYYY-MM-DD.md` — website feature + email + Facebook + publishing materials (`tools/weekly-newsletter/CONTENT_PACKAGE.md`)  
- `blog_draft_YYYY-MM-DD.html` — three English article drafts for Julie’s review  
- `blog_draft_log.txt` — run log  
- `shared/newsletter_topic_history.json` — 28-day topic memory  
- `shared/newsletter_url_history.json` — 84-day URL memory  

Do not treat these files as published site content. Publishing goes through `blog/` + `en/blog/` after Julie chooses an article.

Sunday **email** automation (research + 6 a.m. send): `tools/weekly-newsletter/`.
