# Teaching-page video (page → script)

One unique Spanish lesson per **teaching page**. Presenter and persona: [AVATAR-JULIE-ASSISTANT.md](../../../AVATAR-JULIE-ASSISTANT.md). Method and templates: [page-to-script.md](page-to-script.md).

## Do not run a page until named

Do not pick a URL. Do not write a homepage brief. Wait until the user names a teaching page.

Skip unless the user explicitly asks: `index.html`, ad landings, privacy/terms/SMS, thank-you, site search, weekly news digests, `sources/` mirrors, staff tools.

## Order (do not merge)

1. Read the avatar file (persona + agency locks).
2. **Breakdown** from the live page + HTML. Not a script.
3. Stop. User approves or marks up the breakdown.
4. **Script** from the approved breakdown only: YouTube narration (hook, through-line, spoken Spanish), not a webpage read-aloud. Polished first draft. Stop for approval.
5. Stop. User approves the script.
6. HeyGen / YouTube / embed are later. Not this skill.

After a video is public on YouTube, Google ranking setup is `data/youtube-videos.json` + `npm run youtube:seo` (chapters, Spanish captions, Education category, educational playlist) and VideoObject + video tags in `sitemap.xml` on the matching teaching page. Do not skip captions or the playlist.

## Runtime

- HeyGen **Free**: max 1 minute, watermarked — private preview only.
- **Creator** (required before public): typical teaching video **90–180 seconds**. Cut before covering every table.

Calm Spanish: about **130 spoken words per minute**.

## Output

Write both artifacts as markdown the user can edit. Follow the templates in [page-to-script.md](page-to-script.md).
