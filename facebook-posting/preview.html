Vista previa de Facebook

El script main.py no guarda la vista previa en esta carpeta. La escribe aquí:

FB/post-preview.html (carpeta FB en la raíz del proyecto, al mismo nivel que facebook-posting).

Abrir FB/post-preview.html (última regeneración)
También se guarda una copia con fecha: FB/post-preview-YYYY-MM-DD.html para distinguir semanas.
Si el enlace no abre, en Finder: Mejor-Vida-HTML → FB.

Para regenerar el HTML (y FB/post-package.json):

cd facebook-posting
python3 main.py --dry-run

Nota: post-preview.html suele estar en .gitignore; hace falta ejecutar main.py al menos una vez en esta máquina.
